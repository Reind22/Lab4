# PELab4 — Сетевые крестики-нолики

Документация проекта групповой лабораторной работы.

## Разделы

- [API](api/index.md) — справочник по классам и интерфейсам, сгенерированный из XML-комментариев.
- [README репозитория](https://github.com/koitorra/PELab4) — описание сборки, запуска и архитектуры.

## Архитектура

Решение состоит из четырёх проектов:

| Проект | Назначение |
|---|---|
| `TicTacToe.Shared` | Общие модели, контракты сетевого протокола |
| `TicTacToe.Server` | TCP-сервер, лобби, БД рекордов (SQLite) |
| `TicTacToe.Client.Core` | Игровая логика и ViewModel'и (без UI) |
| `TicTacToe.Client` | Avalonia UI, привязки, стили, локализация |
